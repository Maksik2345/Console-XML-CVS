# Статистика зданий из CSV и XML

Консольное приложение на Java 21 читает справочник зданий, показывает дублирующиеся записи и подсчитывает здания высотой от одного до пяти этажей по городам. Программа замеряет время чтения файла и подсчёта статистики.

Записи считаются одинаковыми, если совпадают город, улица, номер дома и этажность. В отчёте о дублях выводится общее число появлений записи. При подсчёте по этажности каждое такое здание учитывается один раз.

## Запуск

1. Откройте `pom.xml` в IntelliJ IDEA как Maven-проект и выберите JDK 21.
2. Запустите класс `io.github.maxik2345.data.Main`.
3. Введите путь к файлу с расширением `.csv` или `.xml`. Для завершения введите `exit`.

После отчёта или сообщения об ошибке программа снова запрашивает путь. Для проверки на полном наборе данных можно открыть `address.csv` и `address.xml` из задания.

## Формат файлов

В CSV первая строка содержит обязательные колонки `city`, `street`, `house` и `floor`. Разделитель полей — точка с запятой. Сохраните этот пример как `example.csv` в UTF-8.

```csv
city;street;house;floor
Омск;Мира;67;2
Омск;Мира;67;2
Омск;Ленина;12;5
```

В XML те же поля задаются атрибутами элемента `<item>` внутри `<root>`.

```xml
<?xml version="1.0" encoding="UTF-8"?>
<root>
    <item city="Омск" street="Мира" house="67" floor="2"/>
    <item city="Омск" street="Мира" house="67" floor="2"/>
    <item city="Омск" street="Ленина" house="12" floor="5"/>
</root>
```

## Пример работы

```text
Введите путь к CSV или XML (exit — выход): example.csv
Дублирующиеся записи:
Омск, Мира, дом 67, этажей 2 — появлений: 2
Количество зданий по этажности:
Омск — 1 эт.: 0, 2 эт.: 1, 3 эт.: 0, 4 эт.: 0, 5 эт.: 1
Время обработки: 12.500 мс
```

## Структура проекта

| Компонент | Ответственность |
| --- | --- |
| `Main` | Точка входа |
| `App` | Ввод пути, выбор парсера и вывод отчёта |
| `parser` | Общий интерфейс `DataParser`, чтение CSV через Apache Commons CSV и XML через StAX |
| `model` | Запись о здании `DataRecord` |
| `statistics` | Подсчёт повторений и распределения зданий по этажности |
